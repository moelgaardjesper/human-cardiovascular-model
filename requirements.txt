# WHY EXACT PINS AND NOT RANGES. Every number this project publishes — the
# validation table, the comparison against each source, the suite result — is a
# floating-point output of these libraries running this model. A reader who
# installs `numpy` bare in 2027 gets a different numpy and cannot reproduce the
# figures in the paper, and would have no way to tell whether a disagreement was
# their environment or our error. The pins make that distinction recoverable.

# and the note in README. Earlier versions are NOT claimed to work; they are
# untested at the freeze, which is a different statement from incompatible.
#

# recorded because Flask's dependency tree moves independently of Flask, and a
# reproduction needs the whole set, not the parts we happen to import by name.
