## Sources cited in `model/` whose identifier no test repeats

A paper justifying a parameter with nothing checking it is the citation form of "documented mechanism, silently inert" — this repository's most frequent defect class. Each of these is a candidate test, not necessarily a defect.

**READ THE HEADING LITERALLY.** This tool matches PMIDs and DOIs, so a test that names a paper in prose WITHOUT its identifier is invisible here and its source lands in this list. One such case is known (Schipke, named in a test docstring with no PMID beside it). That is a defect in the CITATION rather than necessarily in the coverage — the project's own rule is that a test carries the DOI or PMID of the source it asserts — but it means this list is an UPPER BOUND on genuinely untested sources.
